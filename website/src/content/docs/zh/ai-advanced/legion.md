# 军团：一个秘书，自成军团

活儿多的时候，秘书不会一件件排队做。它把活分好，派出一批**伙计**分头去办，做完把结果汇总交给你。这套能力，我们叫「军团」。

## 什么时候会用

你不用选，也不用开关，秘书按活来定。彼此独立、每个都要花不少时间的活，最适合派出去：

- 几十份文档要看，每份都要提炼要点
- 一批代码要逐个审
- 一堆文件要整理归类

活不多时，它自己做就够了。

## 一次能派多少

一场任务里，没做完的伙计最多 1000 个。超出的那一次派出会被退回并说明，等一部分做完，秘书再接着派。

派出去的伙计全都会开工，但同一时刻向模型发请求的数量，由旗鱼根据接口的反馈自动调节：没被限流就逐步放开，被限流就先缓一缓再放。多出来的请求会先排队，界面上标成「等模型空位」，不是卡住了。并发数不需要你配，也没有地方可配。

## 伙计能做什么

- **知道你交代过什么**：开工时默认带着这场对话里你说过的话和秘书已经说出口的结论；秘书也可以只带最近几轮，或者不带。
- **干本机的活**：读写、搜索、整理本机文件，在本机运行命令，用秘书已经装好的技能。
- **交卷**：做完把结果交给秘书，由秘书汇总后告诉你。

## 伙计不能做什么

伙计能干活，但不能替你做主：

- 不能自己问你问题、要密码，也不能主动联系你
- 不能发邮件、改日程、建关切
- 不能改任务的计划，也不动产出物面板
- 不碰终端窗格，命令都在本机后台运行
- 不能再往下派伙计，伙计之间也不能互相传话

需要你批准的操作，不在伙计那边问，而是留在你正在看的这场对话里问你，遵守你选的审批方式（严格 / 宽松 / 自由 / 替我审批）。想更保守，可以在设置里打开「额外禁止伙计做高风险操作」，打开后高风险操作直接拦住，不再问你。

伙计也不是独立的对话：不会出现在「最近对话」里，不会作为单独的对话保存，不写进长期记忆，你也不能切进某个伙计的对话。在连着远程服务器（SSH）的终端对话里，暂时没有派伙计的能力。

## 你会看到什么

- 对话里出现一行「派出 N 个伙计」，进度收在一行里，点开才看每个伙计在做什么。
- 每个伙计的结果全文都存成文件；结果较长时，对话里只留结尾一小段和存放位置。另有一份总览，一个伙计一行，写着状态和结果放在哪。
- 点停止，所有伙计一起停；还有伙计在干活，秘书不会收工。

## 关于花费

每个伙计都要向模型发请求，派得越多，用量越大，大致随人数成比例增加。旗鱼不会在派出前估算费用，也不会为花钱弹确认。伙计问模型花掉的，算在这场对话的消耗里。如果你的模型按量计费，批量干活前留意一下。
