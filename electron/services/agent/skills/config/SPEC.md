# 旗鱼配置管理技能 SPEC

> Last verified: 2026-09-23

## 职责

让秘书能替用户查看和调整旗鱼自己的设置：界面、终端、渠道凭证、邮箱/日历账户、MCP 连接器、AI 模型配置、联网搜索，以及 SSH 主机。设置页和主机列表仍然可用，两边改的是同一份。

## 设计目标

### 秘书要能管模型，不必把人赶到设置页

用户会说「帮我加个 DeepSeek」「看看现在有哪些模型」。这和「帮我加个邮箱」「接一个 MCP」是同一类事，不该只有设置页能做。

- **能看清已有模型**：名字、模型名、接口地址、类型、是不是当前默认、Key 填了没有。不能只报「有几项」。
- **能加、改、删**：一条一条来，禁止整表覆盖把已有模型冲掉。加改删共用一个入口，用动作区分，不拆成三个工具。
- **Key 不回显**：对话里只说「已配置 / 未配置」，不把密钥原文带出来。
- **第一条自动成为默认**；删掉当前默认时，切到剩下的第一条。新加的第二条起不自动抢走当前正在用的默认（除非用户明确要求设为默认）。
- **不能删自己正在用的，也不能删它挂着的视觉模型**：这次对话赖以说话的那条（设置页则是当前默认）删了就断；挂着的视觉模型删了，看图会立刻失效。要删，先换一个再说。秘书和设置页同一套规矩。
- **有别的模型还挂着它当视觉模型时，先不删**：点名是谁、说明删了会解除关联，等用户点头再删并解开。不要悄悄摘掉，也不要留下指向已删模型的空引用。秘书和设置页同一套。
- **不能删最后一条**：删光了就没有可用模型。先加上别的再删。秘书和设置页同一套。
- **尽量测一下能不能连上**：测失败也先存下来并说明原因——设置页也允许不测就保存。
- **不做**：不替用户猜供应商默认地址；不自动把新模型切到当前正在聊的这次会话。

### 秘书要能管联网搜索，不必把人赶到设置页

用户会说「换成 Kimi 搜索」「帮我把博查的密钥填上」「现在用的是哪家」。这和换模型是同一类事。

- **能看清每一家**：开没开、当前用的是哪家、搜索密钥填了没有。智谱、Kimi、DeepSeek 没单独填密钥、但模型里已经有同一家的密钥时，要说沿用模型密钥，不要说成没配。档位（智谱哪一档、Kimi 哪一档、Google 的搜索引擎编号）也要看得见。
- **一家一家改**：换当前使用的那家、开关、给某一家写入或清掉密钥、改档位。没提到的保持原样——给 Kimi 填密钥不能把博查的密钥冲掉。
- **不能新造一家，也不能删掉一家**：可选的服务商是内置的。
- **密钥不回显**。
- **改完马上生效**：接下来的搜索用新的，设置页跟着变，不用重启。
- **不做**：不替用户去申请密钥；不把密钥原文写进对话。

### 列表型配置一律走「加一条 / 改一条 / 删一条」

邮箱、日历、MCP、AI 模型、SSH 主机都是列表。整表写入会覆盖别人已经配好的项，所以列表本身只读展示，增删改走专用入口。

### 秘书要能管主机，不必把人赶到主机列表

用户会说「帮我加一台 10.0.0.5」「把那台测试机的密码改一下」。这和加邮箱、加模型是同一类事。

- **能看清已有主机**：名字、地址、端口、账号、在哪个分组、密码或密钥填了没有。不能只报「有几项」。
- **能加、能改、能删**：一条一条来，禁止整表覆盖把已有主机冲掉。加改删共用一个入口，用动作区分，不拆成三个工具。
- **密码和密钥口令不回显**：对话里只说「已配置 / 未配置」，不把原文带出来。
- **可以写入密码和私钥路径**：用户把密码交给秘书时，秘书能存下来，之后能连。改的时候没提到的项保持原样——改地址不必重填密码。
- **可以指定分组**：已有分组就放进去；用户说了新组名就建这个组再放进去。
- **改完列表马上跟上**：加、改、删之后，主机列表立刻变，不用重启、不用手动刷新。
- **不做**：不替用户猜跳板机；加完不自动去连。
