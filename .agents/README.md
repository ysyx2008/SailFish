# 协作规范维护

## 一个启动入口

`AGENTS.md` 保存项目定位、协作底线及动作路由，是新对话唯一必读正文。Cursor 的 `project.mdc` 和根目录 `CLAUDE.md` 指向它；专项适配只保留必要的触发条件与引用，不复制正文。

## 按任务读取

- `rules/`：SPEC、代码查询、提示词、OOP 边界、界面验证和想法本规则。
- `skills/`：测试、审查、提交、SPEC 管理和发布流程。
- `project.md`：项目分支、初始化、验收和本机可选技能。
- `workflow.md`：交付、Git 合入和收尾细则。
- `docs/architecture.md`、`docs/product-philosophy.md`、模块 SPEC 和当前方案：项目知识。

所有路径从仓库根目录理解。新增规则同步 AGENTS 的触发条件；同一要求只在一个权威位置维护，其他文件仅引用。无需因新增规则而新增编辑器入口。旧 Cursor 技能目录仅为兼容入口。

## 复用与验证

复用时替换 AGENTS 中的项目定位、project.md、项目知识及技能中的命令；develop、review、批次标签是旗鱼约定。当前尚未抽成通用框架发行包。

静态检查入口和动作路由目标；实际加载需在各编辑器的新对话中验证规则来源和具体约束。再用真实任务检查能否定位模块、守住边界并完成交付；不能用引用存在代替行为验证。已加载且未变化的正文不重复读取。

本机未跟踪的 Steam 技能不移动、不公开。历史 Plan 保留旧路径，产品中对 Cursor 格式的识别保持原样。
