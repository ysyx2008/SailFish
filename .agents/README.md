# 人与 AI 协作规范

## 目录职责

- 根目录 `AGENTS.md`：读取策略、文档权威来源、工具降级要求。
- `rules/`：与编辑器无关的规则正文。
- `skills/`：以 SKILL.md 组织的操作流程；其中测试、发布命令仍针对 SailFish。
- `project.md`：本项目的分支、工作树、初始化和验收约定。
- `docs/architecture.md`、`docs/product-philosophy.md`：旗鱼架构地图和产品目标。
- `.cursor/rules/`：保留 MDC 条件与正文引用；`.cursor/skills/`：保留兼容技能入口。
- 根目录 `CLAUDE.md`：指向通用入口。

所有路径从仓库根目录理解。普通 Markdown 不假定被任何工具自动注入；适配入口明确要求打开正文。新增规则需同步 AGENTS.md 的触发条件和对应适配入口，正文只改一处。

## 复用边界

目前完成目录中立化，还不是可直接发布的通用框架发行包。复用时替换 project.md、架构和产品文档，以及技能中的项目命令；重新检查工作流中 develop、review 和标签等项目约定。保留隔离工作树、按风险验证、用户验收后合入等原则。

## 验证方式

静态检查入口目标、适配层与正文对应关系和旧路径引用。编辑器真实加载需分别验证：在新对话询问规则来源，并要求读取正文中某项具体约束。静态检查不能证明客户端已自动加载。

未纳入 Git 的本机 Steam 发布技能不随迁移移动或公开；需要时仍可读取旧入口。历史 Plan 的旧路径保留作为历史记录，产品代码对 Cursor 格式的识别也保持原样。
