# 组织架构图版式重做（方案 B）

日期：2026-10-27
状态：已完成，待用户验收

## 为什么要改

现在这张图不是「树」，是左边挂了几条竖线：没有父到子的连接线，子级竖线和下一级平级节点的竖线落在同一个 x 上，看起来像上下级；团是一个撑满整行的空盒子；同一层有的节点在盒子里、有的是裸胶囊。层级关系只能靠缩进猜。

目标：改成真正自上而下的组织图——根居中，团成列，成员纵向排列，所有父子关系用直角连接线画出来。

## 版式

```
                          ┌────────────┐
                          │   秘书      │
                          └─────┬──────┘
                 ┌──────────────┴──────────────┐
                 │                             │
           ┌──────────┐                  ┌──────────┐
           │  研发组   │                  │  运营组   │
           └─────┬────┘                  └─────┬────┘
          ┌──────┴────────┐                    │
          │               │              ┌─────┴────┐
     ┌─────────┐   ┌──────────────┐      │  投放组   │
     │  文档    │   │ 团「项目团」   │      └─────┬────┘
     └─────────┘   │ 待验收 · 群聊 │            │
                   ├──────────────┤      ┌─────┴────┐
                   │ 前端          │      │  小投     │
                   │ 后端          │      └──────────┘
                   └──────────────┘
```

- 根（秘书）在最上方居中，下面是它名下的团/散人。
- 团是一个纵向列：团头（团名、验收结论、群聊入口）+ 成员自上而下排列。
- 没进团的人（如「文档」）和团是平级的兄弟分支，各自带自己的下级。
- 组长名下再有组，就在组长下面继续长，父节点始终居中压在自己的子树上。

## 容器与视觉语言（统一）

- 节点统一用圆角矩形卡片（10px），不再用胶囊；卡片底色用主题的「抬起层」`--bg-surface`，边框 `--border-color`，三种主题都浮得起来。
- 团卡片用 `--bg-secondary`，圆角 12px，内部成员卡片纵向排列且等宽；团头一行放团名、验收徽章、群聊按钮（不再被推到面板最右边）。
- 组长：accent 色描边 + 名字旁一个小皇冠；头像始终显示名字首字（不再用皇冠顶掉首字）。
- 状态只保留两处：头像右下角状态点 + 角色行里的状态文字；验收人小盾牌保留，其余强调一律去掉。
- 连接线 2px，颜色用 `--text-secondary` 混 45% 透明（比普通边框实一点，三种主题都看得清），只出现在「父 → 子」这一层；每个子分支自己的连接线只连到自己的父，不再和兄弟的线连成一条。

## 怎么实现

- `src/components/Organization/OrganizationNode.vue`（新增）：单个成员卡片，只管显示人。
- `src/components/Organization/OrganizationBranch.vue`：重写成「一层子分支」——负责横向排布、连接线伪元素、团的纵向列、递归渲染下级；删掉原来靠 `border-left` 缩进的写法。左右子树宽度不等时，量两端分支的自然宽度，给窄的一侧补一半差值（行内 padding），父节点和竖干才会落在总线中点；补的是可伸缩空白，不会把整行撑成等宽那么大。挂载时子组件先 mounted，父组件量到的已经是子级补好的宽度，一次成型，不跨帧跳；后续变化用 `ResizeObserver` 重算。
- `src/components/Organization/OrganizationChart.vue`：只留头部、秘书根节点、树的居中容器和空状态；树用 `width: max-content` 居中，窄面板横向滚动，不换行；挂载时把横向滚动放到中间，根节点不会一打开就在视口外。
- `scripts/ui-e2e/organization.mjs`：把「缩进一层」的断言从 `.org-sub .org-sub` 改成按层级属性检查；补「成员在团卡片里纵向排列」「散人与团平级」「总线落在行中心」「父节点压在两端中心连线中点」的断言；加 `E2E_THEME`，同一脚本可以出暗色/浅色/蓝色三种主题的截图。

不复用 mermaid 渲染器：项目里的 mermaid 是全局单例，已按 AI 输出图表的需要初始化成 `securityLevel: 'strict'`、固定浅色、关闭 HTML 标签；组织图要的点击开群聊、头像、状态点、两行文字恰好都在被关掉的那一侧，换一套配置会反过来影响 AI 输出的图表；而且每次状态变化重排整张 SVG 会闪。连接线用几十行 CSS 伪元素就能画准。

不改：组织数据模型、`OrganizationCard`、顶部 dock、团群聊、i18n 文案。

## 风险

- 组织很宽时整棵树会比面板宽：选横向滚动而不是换行，避免连接线跨行断开。
- 团里有人自己再带组这种少见情形，子分支会撑宽团卡片；先接受，真实数据里再调。
- 只动前端版式，后端与落盘格式不变。
