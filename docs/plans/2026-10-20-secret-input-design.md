## 要解决的事

模型设置页的密钥框是一排圆点加眼睛；搜索设置页刚加了同样的眼睛，沿用模型密钥时还把那一把显示在框里。用户的要求：所有密钥都用同一种显示——遮住时露开头 3 位、末尾 4 位，中间固定 8 个圆点（位数不随密钥长短变）；密码不在其内。

## 已定的取舍

- 只有密钥（API Key / Secret / Token）改；账号密码、SSH 密码与口令、AI 面板里命令要输入密码的安全输入框不改。
- 做成一个共用的输入框组件，所有密钥框都用它。眼睛按钮、样式、遮盖规则只存在这一处。
- 输入框只能显示它自己的内容，所以「平时露头尾」只能是不编辑时换一种显示：
  - 没聚焦、没点开 → 输入框只读，里面放遮盖后的文本；
  - 聚焦（要改）→ 换成真实内容、`type=password`，可编辑；
  - 点开眼睛 → 明文，可编辑。
- 「留空」有含义的框（搜索沿用模型密钥）：框本身保持空，沿用的那一把放在占位文字里，遮盖和显示方式与自己填的一样。组件用 `reusedValue` 接这个。
- 遮盖规则是个小的纯函数：少于 16 位一位不露；否则头 3、尾 4，中间固定 8 个 `•`。
- 眼睛按钮的说明文字放进 `common`（`common.secretInput.show / hide`），原来的 `aiSettings.showApiKey / hideApiKey` 随模型设置页换上后删掉，不留两份。
- 显示逻辑抽成纯函数 `describeSecretField`（输入：值、沿用值、是否聚焦、是否点开；输出：类型、框里的文字、是否只读、占位文字），组件只负责接事件和渲染。这样不靠真实窗口也能把状态逐个测到。
