# 密钥框统一 · 方案

状态：**未完成**（2026-10-20 落盘；第一步进行中，第二步等用户有精力验收再做）

设计目标已写进：`src/components/Settings/SPEC.md`「关键取舍」里「密钥有统一的输入框，密码不在其内」；搜索页那一半见 `electron/services/web-search/SPEC.md` 设计目标。

想法本条目：`docs/ideas.md`「其余的密钥框也换成统一的密钥框」。

## 要解决的事

模型设置页的密钥框是一排圆点加眼睛；搜索设置页刚加了同样的眼睛，沿用模型密钥时还把那一把显示在框里。用户的要求：所有密钥都用同一种显示——遮住时露开头 3 位、末尾 4 位，中间圆点补满，显示长度和原密钥一样长；密码不在其内。

## 已定的取舍

- 只有密钥（API Key / Secret / Token）改；账号密码、SSH 密码与口令、AI 面板里命令要输入密码的安全输入框不改。
- 做成一个共用的输入框组件，所有密钥框都用它。眼睛按钮、样式、遮盖规则只存在这一处。
- 输入框只能显示它自己的内容，所以「平时露头尾」只能是不编辑时换一种显示：
  - 没聚焦、没点开 → 输入框只读，里面放遮盖后的文本；
  - 聚焦（要改）→ 换成真实内容、`type=password`，可编辑；
  - 点开眼睛 → 明文，可编辑。
- 「留空」有含义的框（搜索沿用模型密钥）：框本身保持空，沿用的那一把放在占位文字里，遮盖和显示方式与自己填的一样。组件用 `reusedValue` 接这个。
- 遮盖规则是个小的纯函数：少于 16 位一位不露、全是 `•`；否则头 3、尾 4，中间 `•` 补满，输出长度恒等于（去空白后的）密钥长度。——第一版理解成「圆点个数固定、不随长度变」，用户验收时纠正：要的是显示长度与原密钥一致。首尾空白不算密钥的一部分（搜索侧保存时本来就去空白）：全空白等于没填，遮盖按去掉空白后的样子。
- 点进去的那一下**全选**（`select()`，晚一拍执行，且这一拍里用户已输入就不选）：遮盖文本和真实内容长短不同，浏览器按点击位置落下的光标留在同一个序号上，插进去的位置和眼前的字对不上。眼睛开着时不全选。——这一条是代码审查后补的，真实窗口里真点一下才暴露（先按 `End` 再输入的脚本测不出来）。
- 眼睛按钮的说明文字放进 `common`（`common.secretInput.show / hide`），原来的 `aiSettings.showApiKey / hideApiKey` 随模型设置页换上后删掉，不留两份。
- 显示逻辑抽成纯函数 `describeSecretField`（输入：值、沿用值、是否聚焦、是否点开；输出：类型、框里的文字、是否只读、占位文字），组件只负责接事件和渲染。这样不靠真实窗口也能把状态逐个测到。
