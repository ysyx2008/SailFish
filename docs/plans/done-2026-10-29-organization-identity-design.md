# 组织身份与寻址加固

日期：2026-10-29
状态：已完成，待用户验收

用户授权先修身份与组长寻址；预算和层数语义另行设计。

## 范围

- ExpertTeam 记录由所属花名册提供的组长真名，统一解析组长真名和保留别名；建团、休眠重建均接入，不改结构化群聊持久格式。
- 群消息发送者继续通过 TeamSeat 闭包绑定；内部成员发言入口也拒绝非成员身份。别名只影响收件人，不改变发件人、验收资格或叫醒计数。
- 开场说明明确本人姓名、组长与汇报关系。模型看到的群消息、唤醒、敲门和交差正文使用 JSON 字符串引用，换行不能伪造独立系统消息头；群聊原文和界面正文保持原样。
- 系统归属信息与文本署名分开：负责人认可不能从正文推断。共享工作区不新增文件权限隔离，不宣称能阻止一切模型语义误读。

## 验证

针对性测试覆盖真名/别名同路由、未知与跨枝名字拒绝、冒充正文不改变发件人和验收资格、换行伪造消息头、旧称呼及重建；组织与专家团 CLI 端到端、基础回归及独立审查。展示提示词变更供用户验收，追加提交留在 feat/agent-org。
