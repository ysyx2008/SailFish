# 新派默认新团队与历史隔离（2026-10-30）

已实现，feat/agent-org 待验，未合入。用户确认：顶层新派默认新团队，明确指定才续派；组长下派与已有成员续交代留在原团队，不增加用户设置。

实现步骤：
1. 成员、组织视图增加可选teamId；新派服务器生成标识，continue_team参数以旧团队任一成员真名定位；分层座位继承，冷恢复及state.json保存归属。旧成员缺字段按legacy处理，不迁移删除历史；名字仍沿用全会话唯一性与全会话并发上限。
2. 系统看板保留各成员，同时按teamId生成独立视图和看板。恢复时按团队选取历史快照，不让其它团队进入当前人数；根下小组名称避免重复占用历史群聊文件。新增组是本团队内小组，不改已有关系，不增加跨枝权限。
3. 前端按团队标识聚合，续派跨轮仍指向同一团队；不同顶层派出在同轮也独立。团队快照取各自最新版本，详情/成果/群聊延用原会话及成员归属。旧无标识记录按已有可确认结构兼容，不能用文字猜新旧团队。
4. 针对性单元与真实CLI覆盖默认分开/指定追加/下级继承/旧成员followup/冷恢复/错误指定及共享保险丝；UI覆盖三人新团队不显示百人历史、历史入口、卡片与千人性能；独立审查、分阶段提交，不合入。

存储是兼容性可选字段；旧数据可读，不批量重写。旧版续写可能丢掉新归属，切回旧版前建议备份历史目录。工具说明变化随交付展示给用户。
