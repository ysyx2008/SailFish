# 统一叫「知识库」：要改的文案清单

状态：**已完成**（2026-10-18 落盘并实现）

背景：同一个东西，界面多处叫「知识库」，秘书的工具说明和整理分组叫「档案室」。讨论后定向「知识库」统一：行业通用、用户熟悉、改动小。「记忆」和「知识库」的区别靠栏目里的说明文字讲清，不靠换词。曾考虑统一成「档案室」，因为工作量大（中文 76 处加英文 45 处）、用户倾向知识库而放弃，见想法本。

只改面向用户和 AI 的文字；代码、接口、IPC、i18n 键名、技能标识（`archive`）、工具名、磁盘目录名都不动。
