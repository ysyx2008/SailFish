## 实现取舍

1. 各人交回仍立即送达，上级照旧合并敲门；进度与看板沿用既有250ms/1000ms合并窗口，整队全部停止时立即刷新最后状态。群聊与交差不丢失，不以少派人提速。
2. 一次成员行排版绑定同一语言，下一次重新读取；翻译原文、参数替换与实时语言切换不变，不增加跨请求的语言缓存。组织看板的百个小组也只在一次排版开始时读取一次语言。
3. 一次技能目录查询内复用开关读取，仍使用同一启用规则；下次查询读取新配置，不跨调用缓存，不改权限和目录顺序。
4. 保留原有并发闸门。未重构Agent基类、配置服务或持久化系统。
