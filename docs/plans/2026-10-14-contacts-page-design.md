# 联系人核对页（设置 → AI → 联系人）

> 落盘：2026-10-14 · 状态：未完成

## 要解决的问题

联系人结构化以后，用户只能问秘书才知道记了什么；秘书记错、记重（例：梁总、刘玲玲被写进两家公司的备注，没单独成人）用户发现不了。需要一个**平时不占位置、要用时找得到**的地方核对和纠错。

## 用户能感知的样子

- 设置侧栏 AI 组，紧挨「知识库」多一页「联系人」。
- 页头：页名、一句说明、「新增联系人」按钮。
- 顶部一个搜索框，按姓名 / 简称 / 单位 / 角色 / 邮箱电话搜（与秘书查人同一套匹配）。
- 下面是列表，每行：姓名（机构带标记），副标题是单位 · 角色 · 第一个联系方式；右侧「编辑」。
- 点「编辑」在原处展开表单：姓名、简称（逗号分隔）、人 / 机构、单位、角色、联系方式（逐条：邮箱 / 电话 / 即时通讯 + 值 + 平台）、备注。底部：保存 / 取消，左侧「删除」（普通确认）、「合并另一条进来」（选一条，确认后并入当前这条，那条删除）。
- 保存时姓名或简称与别人撞了：不保存，提示和谁撞了、可以用合并。
- 秘书那边改了联系人，页面自动刷新；正在编辑的那条不被冲掉（只提示「这条刚被改过」）。
- 设置 → 技能列表里「本地联系人」那一项旁边加「查看联系人」，点了跳到这页。
- 技能关掉时页面照常能看能改（数据还在），不额外提示。

### 合并规则

当前这条保留：姓名、人 / 机构不变；被并那条的姓名和简称都成为当前这条的简称；联系方式取并集去重；单位、角色当前这条空着才补；备注两段不同就上下拼起来；创建时间取早的。被并那条删除。

## 技术方案

- **后端（contact 模块内）**：新增 `ContactBook` 类，收拢 list / search / add / update / delete / merge，返回结构化结果（created / collision / missing …）。`executor.ts` 改为调它（行为不变）；IPC 也调它，不另写一套。`store.ts` 加变更订阅（写盘后通知），供 main 广播 `contact:changed`。
- **IPC**：`main.ts` 注册 `contact:list|create|update|delete|merge`，广播 `contact:changed`；`preload.ts` 暴露 `contact.*` 与 `onChanged`；`src/vite-env.d.ts` 补类型（类型取自 `@shared/types`，不另定义）。输入/结果类型放 `packages/shared-types/src/contact.ts`（前后端共用）。
- **前端**：新页 `src/components/Settings/ContactsSettings.vue`（用 kit 基础件）；`SettingsModal.vue` 注册 tab `contacts`；`SkillSettings.vue` 给 contact 加「查看联系人」并通知 modal 切页；中英 i18n。
