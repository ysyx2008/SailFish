# 团队统一模型调度、额度与错误展示

日期：2026-11-01

状态：已实现并验证，留在feat/agent-org待验，不合入。

1. 统一请求闸门：所有首次和重试按共享窗口/暂停放行，主请求优先；额度耗尽按稳定供应商码区分并熔断分组，错误终止不占名额。
2. 团队模型选择共享：当前对话切模型作用于所有层级的后续请求；迁移排队及等待重试，保留在途请求和工具执行；备用模型使用对应新闸门。
3. 真实错误传递：保留错误原文/状态/错误码与模型名，重试结束不擦掉原因；排队、冷却、请求已发送分别展示，成员图能看实际原因。
4. 验证共享闸门压力与优先级、额度码分类、取消/迁移/切模型、错误记录恢复及界面；运行隔离CLI和独立审查。测试使用假服务和临时目录，不消耗用户真实额度。

额度协议依据：https://docs.volcengine.com/docs/ark/error-codes?lang=zh&redirect=1 。QuotaExceeded在不同API复用，聊天接口按厂商与接口上下文识别，不靠“欠费”等任意文案关键词分类。


## 实现与自审

- AI公共入口统一计数，纯文本流式复用带工具流式实现，每次重试放掉旧名额再重新获取。前台优先且受窗口/暂停约束，备用模型换新分组；取消排队和退避可即时停止。
- 对话与各层成员共享手动选择版本；正在发出的请求正常收尾，排队/退避请求迁移，实例内自动降级仍可独立。未修改身份提示词、角色规则或工具权限。
- 稳定协议码识别额度；无明确重置时间时分组短时熔断，有明确时间按该时间；只从原文提取重置时间，不拿文案猜账务类别。账户欠费沿用不自动切模型边界。
- 不同模型/错误分别留痕，同一请求周期重复相同错误不刷屏。详情按纯文本显示并可展开，随历史可选字段apiError保存。旧记录没有字段仍兼容，不需要迁移；新增错误字段不会改变既有文件结构。
- 组织图等待状态分别为排队、冷却、退避；冷却结束尚无名额恢复排队。终态清除等待标记；主请求失败级联打断仍保留，主对话可查看导致组织停止的原始原因。
- 自审覆盖目标、名额释放、取消/迁移竞争、备用模型分组、失败清理、身份权限、旧记录及纯文本呈现。Claude CLI外审等待180秒无输出，已停止，**没有取得独立审查结论**。

## 验收与限制

关闭旧验收窗口，在本树运行 `review agent-org` 后生效。先用合成CLI验错误，再用少量成员人工切模型核对后续请求；不需要再花真实套餐额度复现耗尽。

已失败/被打断成员不会仅因选择模型自动复活，仍按原有再交代续跑规则处理。在途请求不强切；新模型可能有自己的排队与冷却。闸门按接口+密钥+模型分组，不会预知厂商账户跨模型共用的账务限额，也不是token预算；真实供应商仍可返回限流。插件入口受闸门约束，插件内部自行重试的行为由插件负责，主进程无法拆分不可见的内部请求。
