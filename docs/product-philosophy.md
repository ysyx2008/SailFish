# 旗鱼产品理念

旗鱼是大模型驱动的私人桌面秘书，能实际操作本机与 SSH 远程环境；日程、邮箱、待办、联系人是核心职能。

## 主动与连续

秘书有自主性：心跳提供运行节律，关切承载监控和定时事项，通过 talk_to_user 主动联系用户。用户关切的故障告警应在首页显著呈现。

任务是一次性、隔离、可并行的工作，桌面端以任务为主；联络是常驻、多渠道汇流、可主动发起的持续关系。各渠道汇入同一联络关系，不割裂上下文。具体界面形态以当前架构和模块 SPEC 为准。

## 用户不用动脑

- 合理默认、能判断就不问；只问用户才知道的取舍。删除、对外发送、花钱等难撤回操作仍需确认。
- 用用户的词，统一命名；一件事一个入口，沿用熟悉惯例，减少设置与无用文案。
- 报错说明发生了什么、下一步怎么办。

## 记忆与扩展

L1 保持当前对话连贯；L2 保存少而精的高频事实并自动注入；L3 长期保存完整经历、按需回忆。L2 与 L3 互补，秘书主动维护记忆。知识库保存用户交给秘书的文件，按需取用。

核心稳定，能力通过 Skill 和 MCP 扩展。
