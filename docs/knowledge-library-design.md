# 知识库设计

> 2026-10-17。这是给档案室定下来的用法，不是实现笔记。

档案室里放的是交给秘书的资料：制度、报告、说明。它和秘书自己记住的事不是一回事。自己记住的事（对某台机器的认识、过往对话）保持原来的找法，这次不改。

一份东西值不值得放进来，看的是：没人提起它的时候，该不该被想起来。值得就放进来。只是以后可能用到的，留在硬盘上，要用时再去翻。

放进来的是原文。秘书写的说明只是导航，用来判断该不该打开，不能拿来当依据。说明必须能对上它所依据的那一版原文。原文换了而说明还是旧的，要标明脱节，不能悄悄盖掉人改过的话。人确认这段说明对新版仍然适用，才重新对齐。

## 自动翻到眼前

每一轮对话都会按这句话去翻档案室，把对得上的线索带进来。这是档案室和普通文件夹的差别：不用先想到「去搜」。

带进来的主要是线索，不是整篇：

- 对上的目录，只有目录本身，不把里面的文件全部倒出来。
- 对上的文件：路径、标题，有一行说明就带上。文件要自己的标题对上才出现，不能因为跟别的文件坐在同一个目录里就跟着出现。
- 另外最多两小段特别贴的原文。整段有字数上限。

范围可以限定在某一级目录及其下级。没限定就是全库。限定之外的文件不会自动出现，目录名和文件名也不进这一个池子。需要时仍可以搜、可以列出来。

目录名和文件名按各自的相似程度算，和正文分开。改一个名字只改这一条，不用把原来的正文重新做一遍。说明还没写好，目录和文件名已经能把位置露出来。说明写失败，或者说明那份索引坏了，不影响目录和文件名。目录和文件名也坏了，才退回正文片段。

正文要多贴，仍看原来那道「意思像不像」的门槛。不为了让长篇资料更容易自己冒出来而把这道门槛放宽。门槛一松，无关的段落会挤进每一轮。长篇资料该由秘书自己意识到要去查，再主动去翻。

个人使用的规模按几千份文件来。名字一条条比，现在够用。等名字多到逐条比变贵，再改用近似查找。现在就开近似查找，条数少，反而更慢，也更容易漏。

## 秘书主动去查

搜索、打开全文、列目录、把这场对话之后的自动翻阅限定在某个目录，一直放在手头。

搜索仍是原来那一个，用一个参数区分两种查法。不填的时候按相关度，和现在一样。选字面的时候，在正文、目录名和文件名里查找出现过的词，不按意思相近来排。

字面查找只在秘书选了这个参数时才走。正文用已经建好的词索引，不把文件再读一遍，也不跑语义。目录名和文件名不写进那份正文索引，避免把自动翻阅带偏；它们本来就在档案室的目录里，对一下词即可。连续编号保持整段，不从中间拆开。

对上的目录只给出目录本身。文件名对上的，给出该文件的路径、标题和文档编号；正文里没有这些词，就不附原文。正文对上的，给出含这些词的片段和文档编号。同一份文件只出现一次。顺序是：对上的目录，对上的文件名，然后是正文片段。默认几条，有上限。常见词靠现有的词频压住，不把整个库倒出来。

编号如果只写在文件名上、正文里没有，字面查找也能靠文件名找到。主机上记下的短事实、过往对话不在这次字面查找里。

打开全文仍按文档编号。这些文档不在磁盘路径上，不能拿读普通文件的办法去读。

## 整理目录

放进文件、删一份、建目录、挪文件、改目录名、删目录，放在一个需要时才拿出来的技能里。不摊在每一轮的工具里。

可以建子目录。空目录会留下来，直到被删掉。文件挪走之后，原来的目录还在，除非把它删掉。

挪文件、改目录名时，目标位置已经有东西就不硬盖。改名只检查跟着走的这些文件会不会在新位置互相重名。库里别处本来就有的同名文件，不因此拦住这次改名。

删掉一个目录时，里面的文件和下级一起删掉，删掉的文件再搜不到。目录里只要还有文件，就先征得同意，并说明有多少份。空目录直接删。删单独一份时，自己放进去的可以直接删，用户放进去的要先问。没有回收站。

秘书放进档案室的文件，正文不进入这一次对话。清空全库、导入导出、重建索引只在设置里。清空必须亲手打出指定的字。

说明在空闲时慢慢补，不占用放入文件的那一下。一次补多少、一天补多少有上限。没指定用哪个较省的模型，就不自动写。静默时段不写。人在界面上能看见说明、能改。

## 设置里怎么看

记忆和档案室仍在这一页，用设置里统一的标签切换：只有文字和一条当前位置的线，不另画一套盒子。

档案室左边是目录树。根在最上，下级缩进，可以展开、收起。空目录也在树上。点哪个目录，旁边只列它直属的文件；再下一层在树上，不混进这份列表。在目录上右键可以新建子目录、改名、删除；根目录只能新建。删目录时里面还有文件会先问，并说明有多少份，空目录直接删。在文件上右键可以删除。把文件挪到别的目录，在打开这份文件之后做。没有回收站。文件用和输入框附件同一套图标，也就是本机给这种文件准备的系统图标。档案室只留着文件名和类型，没有原来的磁盘位置，所以按类型取一次，同一类文件共用。系统给不出时，再用附件那套备用图标。

搜索、来源筛选用设置里现成的输入框和下拉。说明写了多少收成一行现状。长度、入库方式、维护留在列表下面，不跟列表抢第一屏。

现在这批文件大多堆在根上。树做出来也会先只有根，文件进了目录，层级才会展开。

## 明确不做

- 不改秘书记住的事、过往对话现在的找法。
- 不把自动翻阅的门槛放宽。
- 不把说明当成可以引用的条文。
- 不把正文整份塞进每一轮对话。
- 不写「遇到某种说法就去搜知识库」这类叮嘱。
- 现在不为名字做近似查找。
- 不做章节级索引、废止标记、文件之间的冲突发现，也不把过往对话和档案室的线索并成一层。
